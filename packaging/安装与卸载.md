# 题眼 LitRadar 安装 / 卸载说明

> 普通 Windows 用户优先下载 `LitRadar-Setup-0.11.1.exe`，双击后会自动装引擎和 DSH 插件；下面的手动包是给需要自己控制安装位置或排查问题的人。

本目录是一个完整的分发包：

| 文件 | 作用 |
|---|---|
| `litradar-dsh-plugin-*.tgz` | DSH 插件包（左侧栏入口 + 面板 + 引擎托管） |
| `litradar-engine.zip` | 本地引擎源码（Python，检索/抓全文/卡片/简报/界面） |
| `install.ps1` | 一键安装（解压引擎、写配置、装进 web / desktop profile） |
| `uninstall.ps1` | 一键卸载 |
| `README.md` | 本说明 |

前置条件：Windows、Python 3.11+、已安装并能正常启动 DeepSeek Harness（DSH）。

## 一、安装

在 PowerShell 里进入本目录：

```powershell
# 只装 web profile（命令行 `dsh web` 用）
.\install.ps1 -Profile web

# 只装桌面版（DeepSeek Harness 桌面应用）
.\install.ps1 -Profile desktop

# 两个都装（默认）
.\install.ps1
```

可选参数：

- `-EngineDir "D:\Tools\LitRadar"`：引擎解压位置，默认 `%LOCALAPPDATA%\LitRadar\engine`
- `-Python "C:\...\python.exe"`：指定解释器，默认自动找 `python`

安装脚本做了四件事：

1. 把引擎解压到 `-EngineDir`；
2. 写 `~/.litradar-suite/config.json`（引擎路径、Python 路径、数据目录）；
3. 用 `dsh plugin --profile web add <tgz>` 装进 web profile；
4. 桌面版则在该 profile 目录执行 `pnpm add link:<tgz>`，并把包名追加进 `dsh.profile.bundles`。

装完**完全退出 DSH 再重开**，左侧栏「新会话」下面会出现「题眼 LitRadar」。

## 二、卸载

```powershell
.\uninstall.ps1 -Profile web       # 只卸 web
.\uninstall.ps1 -Profile desktop   # 只卸桌面版
.\uninstall.ps1                    # 都卸
.\uninstall.ps1 -PurgeData         # 连 ~/.litradar-suite 的路径配置一起删
```

卸载脚本做两件事：`dsh plugin --profile web remove litradar-dsh-plugin`（桌面版用 `pnpm remove`），再把包名从 `dsh.profile.bundles` 移除。重开 DSH 后入口消失。

> 注意：DSH 自带的「插件」页面只管理插件市场里装的包，本插件是本地 tgz 安装的，**不要**在那里点卸载；以本目录的 `uninstall.ps1` 为准。

## 三、手工安装（不想用脚本时）

```powershell
# web profile
dsh plugin --profile web add "D:\path\to\litradar-dsh-plugin-0.11.1.tgz"

# 桌面版：先完全退出 DSH，然后
cd $env:USERPROFILE\.dsh\profiles\desktop
pnpm add "link:D:\path\to\litradar-dsh-plugin-0.11.1.tgz"
# 再编辑同目录 package.json，把 "litradar-dsh-plugin" 加到 dsh.profile.bundles
```

## 四、验证装好了

```powershell
dsh --profile web --dump-config | Select-String litradar
```

看到 `- id: litradar` 即为挂载成功。打开界面后：

- 左侧栏点「题眼 LitRadar」；
- 右上状态点绿色，显示「本地引擎 · deepseek-flash」；
- 「模型」下拉里的模型来自 DSH 自己的 provider 配置，不是写死的两项。

## 五、数据放在哪

- 引擎默认写到 `~/.litradar-suite/config.json` 里的 `data` 目录；
- 开发机（本机仓库 `D:\Projects\LitRadar`）仍然是 `D:\Projects\LitRadar\workspace`；
- 每次分析的产物：`<data>\runs\<时间戳>\report.md`、`papers.csv`、`summary.json`。
