# 文献批处理 MVP · 工作清单

> 目标日期：2026-12-27 交参赛 PDF；本清单覆盖 **2026-11-18 → 2026-12-20** 的开发期，12-21 起冻结代码只做报告。
> 一句话目标：**给一个研究方向，批量跑完「检索 → 筛选 → 抓全文与图 → 抽卡片 → 出证据简报」全链路，每条结论都能回到原文的页码/图号。**

---

## 0. 验收线（达不到就不算完成）

| 指标 | 门槛 | 怎么测 |
| --- | --- | --- |
| 检索召回 | ≥ 80% | 3 个方向各准备 20 篇"金标准"文献，看命中几篇 |
| 去重后重复 | 0 条 | DOI 相同或标题指纹相同即判重 |
| OA 全文获取率 | ≥ 90% | 在 PMC 有记录的样本中统计 |
| 卡片字段完整率 | ≥ 90% | 8 个必填字段：设计/系统/因素/对照/n/组学层/结局/结论 |
| 证据可定位率 | **100%** | 每条结论必须带 `section + page` 或 `figure/table` 编号 |
| 人工抽检准确率 | ≥ 90% | 随机抽 20 条结论回原文核对 |
| 单篇成本 | < 0.05 元 | 用便宜模型（DeepSeek / GLM Flash 档），记录 token |
| 批量吞吐 | 100 篇 < 30 分钟 | 不含 PDF 下载瓶颈时 |

**三个测试方向**：黄花棘豆抗锈、大麦内生菌、青贮品质（或香豆素根际，看你毕设定哪个）。

## 1. 不做清单（贴在显示器上，改一条要写理由）

- 账号体系、登录、多用户
- 云端部署、Docker 集群、K8s
- 图表复刻（chart-to-code）
- 实验方案生成（gap/design 只留字段，不实现）
- 浏览器插件、Zotero 插件、Word 插件
- 非 OA 全文抓取（付费墙一律不碰）
- 实时协作、评论、版本对比
- PDF 版式精修（能读就行，不追求还原）

## 2. 数据流（一个方向 → 五份产物）

```
topic.yaml
  → [M1] search     检索（Europe PMC + OpenAlex）      → candidates.jsonl
  → [M2] screen     去重 + 规则筛 + LLM 复核            → screened.jsonl
  → [M3] fetch      OA 全文 XML/PDF + 图 + 图注         → fulltext/ figures/
  → [M4] card       每篇一张结构化卡片                   → cards/*.json
  → [M5] export     证据简报（Markdown/HTML）            → brief.md
  → [M6] map        领域聚类小图（静态 PNG）             → map.png
```

每一阶段都能**单独重跑、断点续跑、跳过已完成**。

## 3. 技术栈与仓库结构

| 层 | 选型 | 备注 |
| --- | --- | --- |
| 语言 | Python 3.11+ | 你已有 Python 基础 |
| 检索 | Europe PMC REST、OpenAlex、Crossref | 全免费，无需 key |
| OA 全文 | PMC OA 子集（BioC/JATS XML）、Europe PMC fullTextXML | 只走开放获取 |
| OA 链接 | Unpaywall | 有 DOI 就能查免费版本 |
| 解析 | PyMuPDF（PDF）、lxml（JATS XML） | GROBID 可选，先不上 |
| 存储 | SQLite + 文件缓存 | 单机够用，别上 Postgres |
| 抽取 | LLM 结构化输出（JSON schema 校验） | 便宜模型 + 失败重试 |
| 导出 | Markdown → HTML（复用你比赛的排版模板） | 一份 md 一份 html |
| 界面 | 先 CLI，最后套一层 Streamlit | 界面只做"填方向 + 看进度 + 下载" |

```
litpipe/
├─ litpipe/
│  ├─ cli.py            # 命令入口
│  ├─ search.py         # M1
│  ├─ screen.py         # M2
│  ├─ fetch.py          # M3
│  ├─ card.py           # M4
│  ├─ export.py         # M5
│  ├─ map.py            # M6
│  ├─ store.py          # SQLite + 缓存
│  ├─ models.py         # 数据模型
│  └─ prompts/          # 抽取提示词（版本化）
├─ runs/                # 每次运行一个目录
├─ tests/
│  └─ gold/             # 3 方向 × 20 篇金标准
├─ topic.example.yaml
└─ README.md
```

## 4. 数据模型（先定字段，V2 直接加，不迁移）

```jsonc
// paper
{"pmid":"","pmcid":"","doi":"","title":"","abstract":"","year":0,
 "journal":"","oa_status":"oa|closed|unknown","pdf":"","xml":""}

// card（M4 产出，一篇一个）
{"paper_id":"","pico":{"population":"","intervention":"","comparison":"","outcome":""},
 "design":"","system":"","factor":"","control":"","n":0,"omics":[],
 "stats":"","conclusion":"","limitation":"",
 "evidence":[{"section":"results","page":7,"figure":"Fig.3","quote":"..."}],
 "figures":[{"label":"Fig.3","caption":"...","file":"figures/x.png","linked_para":"..."}],
 "confidence":"high|medium|low"}

// run（每次跑的账本）
{"run_id":"","topic":"","query":"","counts":{"retrieved":0,"dedup":0,"screened":0,"oa":0,"carded":0},
 "cost_cny":0.0,"started":"","finished":""}

// V2 预留，MVP 只占位
{"capability":{},"design":{}}
```

**硬规则**：`evidence` 为空 → 这张卡标 `confidence: low`，简报里单列"待核"，不许当成结论。

## 5. 任务分解（P0 = 必须，P1 = 有余力）

### M0 环境与骨架（4h，11/18–11/24）
- [ ] 建仓库、`topic.yaml` 示例、README 写清三条命令
- [ ] SQLite 建表（papers / cards / runs）
- [ ] 缓存层：URL → 文件，命中即跳过
- [ ] 日志：每次运行落 `runs/<id>/run.log`
- **验收**：`litpipe --help` 能跑，空库能建，重复执行不报错

### M1 检索层（8h，P0）
- [ ] Europe PMC：分页（cursorMark）、字段映射、限速 3 req/s
- [ ] OpenAlex：补引用数、开放获取状态
- [ ] 查询构造：把 PICO 四格 + 布尔式拼成检索式，落 `query.txt` 供复核
- [ ] 断点续跑：已翻过的页记进 `cursor.json`
- **验收**：一个方向能稳定拿回 100–300 条，重复运行结果一致（同 cursor 同结果）

### M2 去重与筛选（6h，P0）
- [ ] 去重：DOI 优先，无 DOI 用「标题归一化指纹」
- [ ] 规则筛：年份、语言、文献类型、是否 review
- [ ] LLM 复核：只要 `include/exclude + 理由` 两个字段，别让它写小作文
- [ ] 输出：`screened.jsonl`，每条带 `include_reason`
- **验收**：20 篇金标准全部进入 include；误杀 ≤ 1 篇

### M3 全文与图表（10h，P0）
- [ ] PMC OA 判定：BioC/JATS XML 拉取，失败降级到 Europe PMC fullTextXML
- [ ] PDF 兜底：Unpaywall 找免费版 → PyMuPDF 取文本
- [ ] 图：从 JATS 的 `<fig>` 抽 label/caption/href，下载图片到 `figures/`
- [ ] 图注 ↔ 正文配对：在 Results 里找 "Fig. N" 引用句，存进 `linked_para`
- **验收**：抽 10 篇，图能打开、图注不空、至少 8 篇能配到引用句

### M4 卡片抽取（10h，P0，核心）
- [ ] 提示词 v1：只抽 8 个字段 + evidence，禁止自由发挥
- [ ] JSON schema 校验，不合格自动重试 1 次，再不行标 `low`
- [ ] 每条 evidence 必须给 `section + page` 或 `figure`，缺则整条丢弃
- [ ] 成本记录：token 数写进 `run.cost_cny`
- **验收**：抽 20 篇，字段完整率 ≥ 90%，evidence 可定位率 100%

### M5 证据简报导出（6h，P0）
- [ ] `brief.md`：按 PICO 分节，每条结论后挂 `[DOI, p.X, Fig.N]`
- [ ] 附"待核清单"：所有 `low` 卡片单列
- [ ] HTML 版：复用你比赛报告的排版模板（深绿/金/纸色那套）
- [ ] 页脚自动写：检索式、日期、条数、模型版本
- **验收**：一份 brief 能直接给导师看，不用再手工整理

### M6 领域小地图（6h，P1）
- [ ] 标题+摘要向量化（本地 embedding 或便宜 API）→ 聚类（HDBSCAN）
- [ ] 每簇给 3 个关键词 + 代表文献 3 篇
- [ ] 静态 PNG（matplotlib，别上交互）
- **验收**：图能看出 3–5 个清晰簇，簇标签不是"cluster 1"

### M7 批量与稳定性（8h，P0）
- [ ] `run` 一把梭：search → screen → fetch → card → export
- [ ] 并发 4，失败重试 2 次（指数退避）
- [ ] 中断恢复：杀掉进程再跑，已完成的不重做
- [ ] 预算闸：超过设定金额自动停
- **验收**：100 篇跑完不断、不重、不超预算

### M8 演示素材（6h，12/21 后）
- [ ] 3 个方向各跑一遍，截图 6–8 张（检索式/进度/卡片/图/简报/地图）
- [ ] 3 分钟录屏：从填方向到出简报
- [ ] 报告里补一节"实测：3 方向 × N 篇 × 成本"

## 7. 批量处理文献的 8 个硬要求

1. **幂等**：同一 URL / 同一 PMID 重复抓取不产生第二份文件
2. **断点**：每完成一篇立即落盘，进程被杀不丢进度
3. **限速**：Europe PMC 3 req/s、Unpaywall 按日配额，超了自动排队
4. **重试**：网络错误退避重试 2 次，4xx 不重试（避免刷爆）
5. **缓存**：原始 XML/PDF 永久缓存，重跑不重复下载
6. **账本**：每次运行记条数、耗时、token、金额
7. **可复核**：检索式、筛选理由、模型版本全部落盘
8. **合规**：只取 OA；请求带 User-Agent 与联系邮箱；不绕付费墙

## 8. 测试与验收（12/14 那天一次性做完）

- 3 个方向各跑一遍，记录：检索条数 / 去重后 / include 数 / OA 数 / 卡片数 / 成本 / 耗时
- 每个方向抽 7 条结论回原文核对，合计 20 条
- 把结果填进报告表格：**"实测：3 方向 × 平均 X 篇 × 单篇 0.0X 元 × Y 分钟"**
- 任何一条"结论无页码"直接判不合格，回去修提示词

## 10. 风险与降级

| 风险 | 触发 | 降级方案 |
| --- | --- | --- |
| 全文抓取被封 | 请求过快 | 降到 1 req/s，只跑 OA 子集 |
| LLM 抽取不稳定 | 字段缺失 | 换模型 / 缩短上下文到 Results 段 / 二次重试 |
| 图表抓不到 | JATS 无 `<fig>` | 只保留图注文本，图片标"缺" |
| 时间不够 | 12/10 还没到 M4 | 砍 M6 + 砍地图，保 M4/M5 |
| 成本超支 | 单篇 > 0.05 元 | 只抽摘要+Results 前 3 段，别整篇塞 |
