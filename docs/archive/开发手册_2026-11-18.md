# 从零开发这个工具 · 手册

> 这份文档回答三个问题：**它在干什么、用什么做的、你自己怎么写出来。**

---

## 一、它在干什么

把"读文献"这件纯人力的活，拆成一条可重复的流水线：

```
输入：一个研究方向（比如"黄花棘豆抗锈"）
输出：一份证据简报，每条结论后面都挂着 [DOI, 第 7 页, Fig.3]
```

人工 vs 机器的分工：

| 环节 | 人现在怎么干 | 机器干什么 | 人还要干什么 |
| --- | --- | --- | --- |
| 检索 | 在 WoS 试检索式，反复改 | 按 PICO 拼检索式，翻页拿 200 条 | 看一眼检索式对不对 |
| 筛选 | 逐条看标题摘要，两天 | 规则筛一遍，LLM 复核一遍，给理由 | 抽检误杀 |
| 读全文 | 下载 PDF，一篇 40 分钟 | 抓 OA 全文和图注，抽成结构化卡片 | 判断卡片有没有读错 |
| 记笔记 | 复制粘贴到 Excel | 统一字段，自动带页码 | 定字段标准 |
| 写综述 | 从头憋 | 拼成带引文的简报 | 下结论、判断价值 |

**它不干的事**：不替你做实验、不判断科学价值、不猜图里的数值、不碰付费墙。

**一篇文献在系统里经历什么**（以 Fu 2024 为例）：
1. 检索命中 → 存下 PMID/PMCID/DOI/标题/摘要
2. 判定是 OA → 下载 JATS XML
3. 从 XML 里抽 `<fig>` 的编号、图注、图片文件
4. 在 Results 里找"Fig. 3"的引用句，跟图配对
5. LLM 按 schema 抽 8 个字段 + 证据位置
6. 校验：没有页码/图号的结论直接降级
7. 进简报，标注"直接证据"

## 二、用什么做的

| 层 | 工具 | 干什么 | 成本 |
| --- | --- | --- | --- |
| 语言 | Python 3.11+ | 全部逻辑 | 免费 |
| 编辑器 | VS Code | 写代码、调试 | 免费 |
| 检索 | Europe PMC REST API | 按关键词检索文献 | 免费、无需 key |
| 补充检索 | OpenAlex API | 补引用数、OA 状态 | 免费 |
| OA 全文 | Europe PMC `fullTextXML`、PMC BioC | 拿全文和图注 | 免费 |
| 免费版定位 | Unpaywall API | 有 DOI 查免费全文 | 免费，填邮箱即可 |
| 解析 | `requests`、`lxml`、`PyMuPDF` | 抓网页/XML/PDF | 免费 |
| 存储 | SQLite（Python 自带） | 存文献、卡片、运行账本 | 免费、无需装数据库 |
| 抽取 | DeepSeek / GLM 的 API | 把全文抽成 JSON 卡片 | 几块钱跑几百篇 |
| 导出 | Markdown → HTML | 出简报 | 免费 |
| 界面（后期） | Streamlit | 填方向、看进度 | 免费 |
| 打包（可选） | PyInstaller | 做成 exe | 免费 |

**不需要**：服务器、云数据库、Docker、React、任何框架。一台笔记本足够。

三个关键接口（先用浏览器打开看一眼，比看文档快）：
- 检索：`https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=oxytropis&format=json&pageSize=5`
- 全文：`https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7100000/fullTextXML`
- 免费版：`https://api.unpaywall.org/v2/10.1038/s41586-020-0000-0?email=你的邮箱`

## 三、你自己怎么写出来（7 步，每步都有验收）

### Step 0 装环境（半天）

```bash
python --version          # 要 3.10 以上
mkdir litpipe && cd litpipe
python -m venv .venv
.venv\Scripts\activate
pip install requests lxml pymupdf pyyaml
```

验收：`python -c "import requests, lxml, fitz; print('ok')"`

### Step 1 先别写代码，手工摸数据（半天，最重要）

用浏览器打开检索接口，看返回的 JSON：字段叫什么、有没有 `pmcid`、`isOpenAccess` 是什么值。
再打开一篇 `fullTextXML`，搜 `<fig`，看图和图注长什么样。

**这一步跳过的人，后面 80% 的 bug 都来自字段名猜错。**

### Step 2 写能跑的 20 行（1 天）

`search.py`：给定关键词，打印前 20 条标题。

```python
import requests
BASE = "https://www.ebi.ac.uk/europepmc/webservices/rest/search"
def search(q, n=20):
    r = requests.get(BASE, params={"query": q, "format": "json",
                                   "pageSize": n, "resultType": "core"}, timeout=30)
    r.raise_for_status()
    for it in r.json()["resultList"]["result"]:
        print(it.get("pmcid"), it.get("doi"), it.get("title"))
search("oxytropis ochrocephala AND rust")
```

验收：能打印 20 条，`pmcid` 有一半不是 None。

### Step 3 加存储（1 天）

SQLite 建一张 `papers` 表，把结果写进去；再跑一次，确认不会重复插入（用 DOI 或 PMID 做唯一键）。

验收：连跑两次，条数不变。

### Step 4 抓全文和图（2–3 天）

- 有 `pmcid` 且 OA → 拉 `fullTextXML`，存 `fulltext/<pmcid>.xml`
- 解析 `<fig>`：`label`、`caption`、`graphic href`
- 图片下载到 `figures/`，文件名用 `pmcid_fig3.jpg`
- 在正文找 "Fig. 3" 的句子，存进 `linked_para`

验收：抽 10 篇，8 篇能拿到图注，5 篇能配上引用句。

### Step 5 调提示词（3–4 天，最花时间）

**先只对 1 篇调**，把输出调成稳定 JSON，再上批量。

提示词骨架：
```
你是文献信息抽取员。只依据给定文本，不许推测。
输出 JSON，字段：design, system, factor, control, n, omics, outcome, conclusion, limitation,
evidence:[{section, page, figure, quote}]
规则：每个结论必须带 evidence；找不到就写 null，不要编。
```

验收：同一篇跑 3 次，字段值基本一致；20 篇里 18 篇字段齐全。

### Step 6 导出简报（1–2 天）

把 cards 拼成 Markdown：按 PICO 分节，每条结论后挂 `[DOI, p.X, Fig.N]`；`low` 卡片单列"待核"。

验收：导出的文件能直接发给导师，不用再手工排。

### Step 7 套界面（2 天，可最后做）

Streamlit 三个控件：填方向、点运行、下载简报。**先保证 CLI 能跑，界面只是壳。**

## 四、让 AI 帮你写代码的正确姿势

| 做法 | 效果 |
| --- | --- |
| 一次让它写整个项目 | 出来一堆跑不通的代码 |
| 一次只写一个函数，先要伪代码 | 可控、能验证 |
| 把接口真实返回的 JSON 片段贴给它 | 字段名不会猜错 |
| 报错原文整段贴回去 | 一次就能修对 |
| 要求它同时给"怎么验证" | 你能判断对不对 |

模板：
> 我在写一个 Python 函数，输入是 Europe PMC 返回的 JSON（结构如下：…），输出是写进 SQLite 的字典。只写这个函数，先给伪代码，再给代码，最后给我 3 条测试用例。

## 五、新手最容易卡的 6 个点

1. **字段名猜错**：先看真实返回，别信记忆。
2. **XML 命名空间**：JATS 解析要处理 `ns`，用 `lxml` 的 `xpath(..., namespaces=...)`。
3. **限速被封**：Europe PMC 控制在 3 请求/秒，加 `time.sleep(0.35)`。
4. **PDF 里没图**：优先用 JATS XML，PDF 只做兜底。
5. **LLM 输出不是合法 JSON**：要求"只输出 JSON"，再写一层 `json.loads` 失败重试。
6. **路径写死**：全部用 `pathlib.Path(__file__).parent`，换电脑不炸。
