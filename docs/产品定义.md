# 产品定义：题眼 LitRadar

> 从一个研究方向，到一套能开题的证据包。

## 形态

本地应用：双击启动，浏览器打开；数据、全文、图、结果全部落本地。不是网页演示，不是浏览器插件。
同一套引擎可挂三种壳：本地 Web、DSH 插件、MCP（Claude Desktop）。

## 输入

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 研究方向 | 是 | 一句话，中英文均可 |
| 约束卡 | 否 | 平台（盆栽/温室/田间/小鼠/体外/纯干）、预算档、周期、是否接受湿实验 |
| 检索范围 | 否 | 起止年份、最多精读篇数（默认 60） |
| 模型 | 否 | API Key、模型名、接口地址；支持 DeepSeek / OpenRouter / 本地网关 |
| 锚点 | 否 | PICO 四格、种子文献 DOI、排除词 |

## 七步流水线

1. 生成检索式（布尔逻辑 + 同义词 + 年份）
2. Europe PMC 检索、去重、落库
3. 相关性筛（0–3 分，自动砍到目标篇数）
4. 抓 OA 全文、图注、图 URL、正文引用句
5. 抽卡片：设计 / 系统 / 因素 / 对照 / n / 组学 / 结局 / 结论 / 局限 / 证据定位
6. 聚合：共识、争议、空白；图型归类；结合约束生成 3–5 个方向
7. 出开题卡，导出 Markdown / Excel / PDF

## 输出

1. 领域全景（做透的 / 在争的 / 没人做的 / 做了也白做）
2. 证据矩阵（N 篇 × 9 列，可筛选排序）
3. 单篇卡片（结论必须带页码/图号/原文引句）
4. 图表复刻清单（图型、所需数据、工具、难度、工时）
5. 方向候选（假说、创新点、条件、周期、成本、风险、匹配度）
6. 开题卡（PICO、处理组、样本量、统计、周计划、预算、预期图表）

## 边界

- 只吃开放获取英文全文；非 OA 只到摘要层，并在卡片标注。
- 无证据定位的结论进“待核”，不进结论区。
- 不生成不存在的文献、数据、图。
- 只给图表复刻方案，不生成成品图。
- 方向是候选，最终由人和导师拍板。
- 没有模型 Key 时只跑到第 4 步，不假装能出卡片。

## 验收

- 换 3 个方向都能出完整六件套；
- 断网重跑、关掉重开，数据不重复、不丢；
- 抽检 10 张卡片，至少 8 张证据定位能对上原文；
- 导出的 xlsx / pdf 能正常打开。
